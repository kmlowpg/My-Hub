Privacy Policy

Last updated: 23 November 2026

My Hub is a personal app used only by its owner. It is not offered to anyone else.

What data it accesses

  • Google Calendar: the owner's events, to display them and to let the owner add, edit and delete them.
  • Gmail (read-only): the owner's incoming messages, to identify tasks and due dates. My Hub cannot and does not send, delete or modify email.

How data is stored

Data is stored only on the owner's own computer. It is not stored on any server run by a third party, and it is not sold, shared or used for advertising.

Processing by AI

The text of selected email messages and notes may be sent to Anthropic's Claude API solely to extract tasks and dates for the owner. It is not used for any other purpose.

Google API Services User Data Policy

My Hub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
